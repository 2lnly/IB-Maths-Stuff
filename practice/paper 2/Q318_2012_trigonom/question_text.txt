The diagram shows the plan of an art gallery a metres wide. [AB] represents a doorway, leading to an exit corridor b metres wide. In order to remove a painting from the art gallery, CD (denoted by L) is measured for various values of α, as represented in the diagram.

(a) If α is the angle between [CD] and the wall, show that L = a/sinα + b/cosα, 
0 < α < π/2. [3 marks]

(b) If a = 5 and b = 1, find the maximum length of a painting that can be removed through this doorway. [4 marks]

Let a = 3k and b = k.

(c) Find dL/dα. [3 marks]

(d) Find, in terms of k, the maximum length of a painting that can be removed from the gallery through this doorway. [6 marks]

(e) Find the minimum value of k if a painting 8 metres long is to be removed through this doorway. [2 marks]
