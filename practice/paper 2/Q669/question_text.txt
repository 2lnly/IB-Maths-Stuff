12. [Maximum mark: 21]

Consider the differential equation dy/dx = (x^3 - y)/x + 1, where y > 0 and y = 3 when x = 0.

(a) Use Euler's method, with a step length of 0.03, to find an approximate value for y when x = 0.15. Give your answer correct to six significant figures.

(b) (i) Write down the value of dy/dx when x = 0.
    (ii) Show that d^2y/dx^2 = 3 when x = 0.

(c) (i) Given that d^3y/dx^3 = 9 when x = 0, find the first four terms of the Maclaurin series for y.
    (ii) Use the Maclaurin series to find an approximate value for y when x = 0.15. Give your answer correct to six significant figures.

(d) (i) It is given that (x^2 - 1)/(x^2 + 1) = 1 - 2/(x^2 + 1).
    Solve the differential equation dy/dx = (x^3 - y)/(x + 1), where y > 0 and y = 3 when x = 0.
    Give your answer in the form y = f(x).
    (ii) Hence, find the value of y when x = 0.15. Give your answer correct to six significant figures.

(e) For 0 ≤ x < 1, explain why the approximate value for y obtained using Euler's method will always be less than the actual value for y.
