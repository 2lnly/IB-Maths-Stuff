13. [Maximum mark: 19]

The function f has inverse f^-1 and derivative f'(x) for all x ∈ R. For all functions with these properties you are given the result that for a ∈ R with b = f(a) and f'(a) ≠ 0

(f^-1)'(b) = 1/f'(a).

(a) Verify that this is true for f(x) = x^3 + 1 at x = 2. [6 marks]

(b) Given that g(x) = xe^x, show that g'(x) > 0 for all values of x. [3 marks]

(c) Using the result given at the start of the question, find the value of the gradient function of y = g^-1(x) at x = 2. [4 marks]

(d) (i) With f and g as defined in parts (a) and (b), solve g ∘ f(x) = 2. 
(ii) Let h(x) = (g ∘ f)^-1(x). Find h'(2). [6 marks]
