Consider the following system of equations

2x + y + 6z = 0
4x + 3y + 14z = 4
2x - 2y + (α - 2)z = β - 12

(a) Find conditions on α and β for which
(i) the system has no solutions;
(ii) the system has only one solution;
(iii) the system has an infinite number of solutions. [6]

(b) In the case where the number of solutions is infinite, find the general solution of the
system of equations in Cartesian form. [3]
