# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

This is a document archive containing IB (International Baccalaureate) Mathematics Analysis and Approaches Higher Level examination papers and markschemes from 1995 to 2023.

**This is not a software project** - there are no build commands, tests, or development setup required.

## Structure

```
Math AA HL/
└── [YYYY] [May|November] Examination Session/
    ├── Mathematics_[...]_paper_[N]_[TZ1|TZ2]_HL.pdf
    ├── Mathematics_[...]_paper_[N]_[TZ1|TZ2]_HL_markscheme.pdf
    └── [Language variants: Spanish, French]
```

- 56 examination sessions (May and November each year)
- Papers 1, 2, and 3 (Paper 3 covers optional topics like Calculus, Statistics, Discrete Mathematics, Sets/Relations/Groups)
- TZ1/TZ2 = Time Zone 1/2 (for May sessions)
- Markschemes are labeled with `_markscheme` suffix

## Naming Conventions

Pre-2019 papers use "Mathematics" naming; 2019+ use "Mathematics_analysis_and_approaches" following the IB curriculum change.
