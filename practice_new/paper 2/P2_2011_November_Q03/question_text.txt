3.	
[Maximum mark:  5]
The number of vehicles passing a particular junction can be modelled using the  
Poisson distribution.  Vehicles pass the junction at an average rate of 300 per hour.
	
(a)	
Find the probability that no vehicles pass in a given minute.
[2 marks]
	
(b)	
Find the expected number of vehicles which pass in a given two minute period.
[1 mark]
	
(c)	
Find the probability that more than this expected number actually pass in a given 
two minute period.
[2 marks]
